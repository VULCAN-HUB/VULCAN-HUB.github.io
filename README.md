- 다운로드: 각 프로그램 GitHub Releases 링크

## 프로그램 소개 규격

ONE LINK와 같은 순서로 프로그램의 용도, 기능, 실행 환경과 검증 상태를 안내합니다.

| 위치 | 작성 규칙 |
|---|---|
| 저장소 소개문 | `프로그램명 — 핵심 용도. Unknown / VULCAN-HUB. 배포 상태.` |
| 홈페이지 카드 | 한 줄 용도 → 용도 설명 → 제공 파일 → 테스트 상태. 버전은 `v`와 실제 릴리스 태그로 표기합니다. |
| 홈페이지 상세 | 용도 → 기능 → 요구사항과 상태 → 다운로드·사용 안내 → 업데이트 내역 |
| README | 프로그램명 → 상태·버전 → 용도 → 다운로드·사용 안내 → 제작자 → 기능 → 요구사항과 상태 → 사용법 → 선택 항목 → 라이선스·공개 정책 |

- 베타·Preview는 **테스트 중**, 일반 공개 배포본은 **공개 배포**로 표시합니다. 일반 릴리스라는 이유만으로 검증 완료를 뜻하는 표현을 쓰지 않습니다.
- 요구사항에는 실제 실행 환경을, 배포 형태에는 설치형·ZIP·포터블과 준비 중인 OS를 구분해 적습니다.
- 확인한 범위와 미검증 범위를 함께 적고, 공개된 검증 결과가 없으면 그 사실을 명시합니다.
- 다운로드는 실제 배포 자산 또는 해당 버전의 릴리스 페이지로 연결합니다. 베타에 `/releases/latest`를 쓰지 않습니다.
- 상세 사용법, 알려진 한계, 저작권과 라이선스 고지는 유지합니다. 개발·빌드와 업데이트 내역은 필요한 프로그램에 추가합니다.
- 기능·버전·배포 파일이 바뀌면 저장소 소개문, README와 `programs.js`의 관련 내용을 함께 확인합니다.

공개 자료에는 [VULCAN 공개 정책 v0.3](https://github.com/VULCAN-HUB/RawBaker/blob/main/PUBLICATION_POLICY.md)을 적용합니다.
